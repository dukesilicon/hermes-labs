Inside the apparatus

The implemented token workshop defines a finite world, legal actions, resource constraints, and an exact goal. The evaluator checks submitted plans; an independent transition/search implementation finds reference solutions. Shared fixture validation limits that independence.

Scope and limitations

Offline checks establish behavior within the supported token contract. They do not establish an innovation event, absence of a composition from pretraining, a human-relative model deficit, or reward suitability.

Source worlds retain the 2-versus-13 valid-plan mismatch. Matching and private execution gates are still open.
