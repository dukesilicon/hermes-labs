2026-10-11 — Add complementary existing-model recombination branch

Issue: The long-term AI reproduction aim needs a narrow existing-model capability test.

Previous position: FH-01–FH-07; human construct/label/signal outline EXP-0001; no implemented evaluation or observed model deficit.

New position — CURRENT HYPOTHESIS / NEW PROPOSAL: Add FH-08: pinned models may lose valid-synthesis performance for withheld versus familiar supplied composition motifs despite independently measured primitive competence. Candidate δ=0.20/τ=0.90 are provisional design decisions, not facts. Fiction-CWR defines objective executable outcomes and registers EXP-0002 as proposed with zero model runs.

Reasoning/evidence: Supplied current task; finite semantics and objective fidelity can test a limited behavior without innovation-event labels. Prior art (not included in this public selection: evaluations/fiction-cwr-v0.1/PRIOR-ART.md) motivates methods, not current-model failure.

Consequences: Eight specs and one reference checker; independent oracle and engineering tests; matched stimuli/necessary motif gates, prospective confirmation, all-model/qualified reporting. Preserve FH-01–FH-07, FM-R01 history, EXP-0001 and separate human/runtime/reward/transfer branches. Prior canonical snapshot (not included in this public selection: ../../archive/research-snapshots/2026-10-11-before-fiction-cwr/SNAPSHOT.md) preserves earlier formulations.

Open questions: Demonstration-relative novelty, residual evidence/difficulty matching, valid familiar alternatives, provider/budget freeze, sample power, practical/human transfer and persistent deficit.

Decision: DEC-0003 (not included in this public selection: ../../decisions/decision-log.md#dec-0003--add-fiction-cwr-as-a-complementary-ai-capability-evaluation).

2026-10-11 — Prepare a workflow attribution alternative

Issue: A future apparent familiar/withheld loss could belong partly to workflow organization rather than to the model generally.

Previous position: FH-08 and EXP-0002 already identify prompt, budget, load and representation alternatives; no model loss is observed. Main private matched stimuli remain unresolved.

New position — CURRENT HYPOTHESIS / NEW PROPOSAL: Add FH-09 and EXP-0003: one pinned model, F/C × self-directed/structured, equal stage opportunities and same-trial history, common evidence/permissions, cumulative ceilings and actual usage. Candidate token evidence pairs, bounded certificates and offline stored-record analysis are separate from the main arm.

Reasoning/evidence: Current supplied preparation brief; inspected Hermes canon and frozen CWR package; article source boundary and Hermes inference (not included in this public selection: evaluations/fiction-cwr-workflow-v0.1/SOURCE.md). Industry commentary motivates the attribution question, not an empirical claim. Offline verification (not included in this public selection: evaluations/fiction-cwr-workflow-v0.1/VERIFICATION.md) concerns apparatus only.

Consequences: Performance is scoped to model–workflow conditions. Require C improvement alongside gap shrink, retain F change and actual cost; F-only deterioration is not support. Equal validity at lower cost is efficiency. Related public development cases do not become private independent tasks through nonce renaming. Retain all failure/null results and source-matching limits.

History/open questions: Sixteen prior records preserved (not included in this public selection: ../../archive/research-snapshots/2026-10-11-before-fiction-workflow/SNAPSHOT.md). Human/runtime/reward/transfer hypotheses and EXP-0002 main arm remain intact. No numeric criterion, model, hidden-compute equivalence, spend or empirical execution is adopted. Model/human runs remain zero.

Decision: DEC-0004 (not included in this public selection: ../../decisions/decision-log.md#dec-0004--prepare-a-separate-workflow-attribution-diagnostic).

2026-10-23 — PT-001 exposes outcome-only attribution failure

Previous/new position: The user provisionally accepts fixed-goal versus problem-transformation as an experimental distinction and requests local execution. PT-001 preserves FH-01–FH-09 and the canonical question. It rejects, for this operationalization, treating a gain over proxy optimization or weak search as evidence of formulation-specific innovation.

Evidence: Actual constructed-strategy outputs, complete bounded enumeration, independent replay and adversarial tests. Direct value optimization reaches all primary ceilings; search-only R-order exactly reproduces R. Value criteria change conflict labels, including in hypothesized no-conflict worlds. No human/model mechanism observed.

Consequences/open questions: Retain outcome/mechanism separation and strengthen objective/search controls. The provisional experimental distinction survives as a question, not a demonstrated mechanism or measured cognitive effect. Recover original source materials separately; next cognitive design must justify formulation coding, resources, usefulness and criteria.
