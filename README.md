# Hermes Labs website

Static HTML, CSS and JavaScript website. No dependency installation or application server is required.

## Upload to GitHub

Extract the ZIP and upload the contents of this folder to your repository, with index.html at the repository root. Upload the extracted files, not the ZIP itself.

## Hosting

Connect the repository to your static hosting provider. Serve this directory as the website root. There is no application build step.

## Before public launch

This is the approved presentation package, not a completed launch audit. Existing noindex directives and local-preview labels are retained. Review publication permissions for the included research records, configure your domain and metadata, and update indexing when ready.

## Contents

The selected branching homepage, four project pages, experimental apparatus, runtime assets and 40 selected research records/downloads. Internal development tools, QA pages, alternate previews and historical drafts are excluded. Local machine paths in the exported PT-001 provenance record are redacted; its canonical source remains in the Hermes working repository.

Research snapshots are static exports. Future research updates must be regenerated in the canonical Hermes workspace and copied into this repository. This package does not monitor the private research repository.

## Vercel setup
Import dukesilicon/hermes-labs into Vercel. Use the repository root. vercel.json selects Other, skips the build, and serves the root directory. No environment variables are required. The website remains noindex until its launch review is complete.
