Project Daydream

Status: exploratory

Phase: Concept formation. Priority: Third, after Project Fiction and Project Imagination.

Working definition

The study of spontaneous internally generated cognition, including associative drift, mind-wandering, incubation, unexpected cross-domain connection, and emergence of potentially useful ideas without immediate external task demand.

Research aim: Determine whether productive off-task cognition can be characterized and instantiated in AI models. The examples identify current investigative scope, not proven equivalent phenomena or fixed membership criteria. Exact boundaries, productivity, computational operationalization, and model architecture remain unresolved.

The migration handover (../../docs/handovers/2026-10-06-migration-handover.txt) restores this spontaneous-cognition emphasis after the broader initialization description. Both the original index (../../archive/Hermes_Project_Index.pre-initialization.md) and pre-handover state (../../archive/migration-snapshots/2026-10-06-before-handover/projects/daydream/README.md) remain preserved. The change follows supplied research context, not an empirical resolution.

Current priority and records

Define the target rigorously and distinguish productive spontaneous cognition from deliberate imagination, generic mind-wandering, generative search, and stochastic model behavior. Do not equate off-task thought or random output with useful innovation.

Read research-question.md, hypotheses.md (hypotheses.md), methodology.md, and research-status.md. No Daydream protocol, dataset, model implementation, experiment, or finding is recorded.

Supporting work retains the project artifact folders. Preserve superseded formulations in the project archive and record substantive changes in the research log (../../logs/research-log.md). Literature in Fiction may suggest relationships, but does not establish a shared question or mechanism.

October 14 program context

Hermes' current thesis (../../lab/mission.md) preserves Daydream as exploratory internally generated cognition. The method requires distinguishing function from random output or extra search. Possible Fiction/Affect interactions remain hypotheses. Existing third priority, provisional boundaries, and absence of implementation/experiments/results remain.
